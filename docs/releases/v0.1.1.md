# v0.1.1 — source-only release

This release closes the first reproducible detection baseline and publishes a
dataset-pixel-free evidence bundle for independent inspection.

Included in the evidence ZIP:

- aggregate formal experiment and per-class test metrics;
- the dataset summary, dataset card, and model card;
- the verified CUDA environment snapshot;
- a package manifest plus per-file SHA-256 checksums.

Not included:

- NEU-DET images or VOC/YOLO annotations;
- PyTorch `.pt` checkpoints or ONNX models;
- local error-gallery images, caches, or absolute workstation paths.

The official NEU-DET page offers the dataset download and citation guidance,
but does not state a recognized standard dataset license. For that reason,
trained derivative weights are not distributed in this release. Clone the
source and train locally after reviewing the upstream terms if you want to run
the Gradio demo.

Formal metrics, ONNX parity, and named-hardware latency remain reproducible
from the aggregate reports committed in the repository. They are portfolio and
research results, not a production quality-control claim.
